# 📊 BCS - Business Checkup System

Sistema web para análise básica de indicadores financeiros empresariais.

---

## 🚧 Status do Projeto

🟠 Em desenvolvimento  
📦 Versão atual: v0.1 (Front-end funcional)  
🌐 Deploy ativo via GitHub Pages  

---

## 🎯 Sobre o Projeto

O BCS (Business Checkup System) é um projeto em evolução com o objetivo de analisar indicadores financeiros e apresentar uma visão clara da saúde empresarial.

Nesta versão atual, o sistema funciona como uma aplicação web simples que permite inserir dados financeiros e visualizar cálculos de indicadores essenciais.

A proposta é evoluir gradualmente para uma plataforma mais robusta de análise estratégica.

---

## ✅ O que o projeto já faz (atual)

- Interface web responsiva
- Entrada manual de dados financeiros
- Cálculo de indicadores básicos
- Exibição dos resultados na tela
- Estrutura organizada em HTML, CSS e JavaScript

---

## 📈 Indicadores disponíveis (atual)

- Liquidez
- Margem
- Indicadores financeiros básicos definidos na lógica do script

*(Os indicadores serão ampliados nas próximas versões.)*
